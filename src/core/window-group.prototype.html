Recent actions

    Proposed rules: Any focused window in this vault triggers group hide. Only visible, non-minimised windows join the recall set. Recall restores surviving members back-to-front, then focuses the most recently used visible member. Independent minimise or close removes a window from recall. An independently restored or newly opened window joins the next hide cycle. If no window can be recalled, use the most recent surviving note window, then any surviving window.

    Still to validate in Electron: window ownership, native child-window constraints, focus events generated during hide/show, and Spaces/fullscreen behaviour. Focus history is a proposed approximation of stacking order, not a claim that we can capture the OS's exact stacking. Position and monitor changes are intentionally not simulated. Other vaults keep their own state.
